# Vendored Swagger UI assets

These files are from `swagger-ui-dist@5.33.1` on the npm registry. The source
package SHA-256 is
`b468ff5f49451f194a739bc245c85b28c7d3d33057a8409a9b2369da37e215b9`.
The upstream `LICENSE`, `NOTICE`, and JavaScript license notice are included.
`swagger-init.js` is PULSE code that loads the local OpenAPI schema.

Only the bundle, stylesheet, favicon, and license files are vendored. Source
maps and the upstream example initializer are not served. Re-vendor and review
these assets when updating Swagger UI.
